# 💡 创意池

> 结合竞品（Stardock Fences / 元气桌面整理 / 腾讯电脑管家 DeskGo / DeskBox）调研与 Roadmap 的差异化创意池。已排期进 Roadmap 的不在此列；落地后移入 Roadmap 并标注版本。

---

## 2026-11-17

### 1. 规则引擎：自定义盒按用户规则参与自动归类

**创意描述**：目前自定义盒（Category.custom）纯手动策展、不参与自动归类。允许用户为任意盒挂载规则（按后缀 / 文件名关键字 / 通配符，如 `*.psd → 设计盒`、`*发票* → 报销盒`），一键整理时命中规则的文件优先流入对应自定义盒，规则未命中的再走默认后缀分类。

**价值**：高。物理移动派竞品（元气/DeskGo）的规则整理只允许改默认分类映射，不支持"一个规则槽位绑到一个用户自建分组"；这是自定义盒体系天然长出的能力，竞品学不来。对有明确工作流（设计稿、发票、安装包归档）的用户是从"能用"到"离不开"的关键。

**可行性**：高。`move_path`/scan 管线与 `Category.custom` 标志均已存在，只需在 Config 增加 `customBoxes[].rules: {pattern, strategy}[]` 并在自动归类决策链最前面插入规则匹配（glob 匹配引入现成 crate，无需自写）。

**优先级**：⭐⭐⭐ 高

### 2. 卸载前自动还原（NSIS 卸载钩子）

**创意描述**：卸载程序时先调用应用自身的"全部还原"逻辑，把 `桌面\桌面整理\` 下的文件搬回桌面原位（搬不动/有冲突的逐项列清单），再询问"是否继续卸载"。NSIS 卸载流程里加一个 custom page / 预卸载步骤。

**价值**：高。卸载是用户流失的最后一刻，也是信任崩塌点——竞品普遍直接卸载，留下"我的文件被塞进一个文件夹、应用没了"的烂摊子（DeskGo 曾因此被大量吐槽）。"卸载也把桌面还给你"本身就能写进 README 当卖点，与 OneDrive 检测、"一切可还原"的产品人设一脉相承。

**可行性**：中。release.yml 已是 NSIS 打包，钩子技术上可行；难点在于卸载器需要独立还原逻辑或静默调用残留的 exe（可在卸载早期于 %TEMP% 解一个 mini helper，或直接以命令行参数 `puredesk.exe --uninstall-restore` 复用主程序 restore_all）。边缘场景（桌面路径被重定向、文件被占用）需要逐项报告兜底。

**优先级**：⭐⭐ 中

---

### 3. 整理洞察面板（基于 moves.jsonl 的使用统计）

**创意描述**：主面板加一个"整理回顾"小页：本周/近 30 天搬移了多少文件、哪些类别最多（应用/文档/图片…）、最高频的来源路径、撤销次数。数据全部来自已有的 `moves.jsonl` 移动日志，零新增采集。

**价值**：中高。四家竞品均无使用洞察，属于纯差异化；对用户是"这个软件真的在帮我"的可感反馈（"本周自动整理了 137 个文件，省去 137 次手动拖拽"），也天然适合日后做周报 toast 或截图分享，是低成本的增长素材。

**可行性**：高。moves.jsonl 已记录 from → to 与成败，前端读日志聚合即可；注意按批次去重、剔除自愈骨架清理的噪音条目、控制读取量（只聚合最近 N 千行）。

**优先级**：⭐⭐ 中

## 2026-11-18（灵感来源：开源灵动岛项目「岛仔」xiaotang-daozai + fly-island）

> 收纳岛本体（顶部灵动岛式状态胶囊：收起态常驻顶部显示收纳/待整理计数，悬停展开分类明细与快捷操作，organize-report 到达时播放活动动画）已直接落地并进 Roadmap。以下为沿"灵动岛"方向继续发散的后续创意。

### 4. 岛上驻留（dwell）提醒：桌面文件躺了几天了

**创意描述**：待整理文件在桌面停留超过 N 天（默认 3 天，可配）时，岛轻膨胀并在待整理区给该项标"已躺 3 天"；超过 7 天的条目排到待整理列表最前并橙色高亮。灵感：DeskBox 的 dwell 稳定态保护 + 岛仔的"信息轻轻出现"。

**价值**：高。桌面凌乱的本质是"文件的惰性"——竞品都在管"搬"，没人管"催"。温和的驻留提示是用户真正开始依赖自动整理的心理推手，也是截图传播的天然素材（"我的桌面没有躺超过 3 天的文件"）。

**可行性**：高。`DesktopItem.mtime_ms` 已随扫描返回，纯前端计算即可（无需新后端）；阈值可先做死配置再进设置页。

**优先级**：⭐⭐⭐ 高

---

### 5. 拖文件到岛 → 分类环（快速手动归类）

**创意描述**：把桌面文件拖到收纳岛胶囊上 → 岛立即展开为分类选择器（各启用盒成一列高亮块，数量多的盒更大），悬停某个盒高亮，松手即 `organize_paths` 归位；按住 Ctrl 松手 = 移动副本（copy-first 借鉴 DeskBox）。

**价值**：高。填补"不想一键整理、也不想开主面板"的中间态：单文件手动归类从右键三步变为一拖一放；岛的顶部居中位置天然是拖拽落点。

**可行性**：中。盒子窗口已有完整 `onDragDropEvent` 处理可移植（box.ts:204-227），岛需补 drag-over 时触发展开、drop 时目标盒高亮；后端 `organize_paths` 命令现成。

**优先级**：⭐⭐ 中

---

### 6. 桌面健康分（岛上的 gamification）

**创意描述**：胶囊左侧显示一个 0-100 的"桌面健康分"（待整理数量、最老驻留天数、近 7 天整理频率加权计算），展开面板显示分数构成与环比；分数达 95+ 时胶囊短暂播放彩虹动画。

**价值**：中高。把"整理桌面"从家务变成可累积的正反馈，四家竞品均无此概念；健康分也是周报/分享功能的天然载体，为后续增长功能铺数据地基。

**可行性**：高。三项输入数据全部已有（scan.items、mtime_ms、moves.jsonl）；纯前端计算，注意权重可调且默认口径保守（待整理 <5 项即 90+，避免永远不及格打击用户）。

**优先级**：⭐⭐ 中

### 7. 岛的全屏感知：检测到全屏应用时自动隐藏

**创意描述**：前台窗口进入全屏（游戏/视频播放器/演示）时，岛自动滑出屏幕隐藏；退出全屏后滑回。可用 Win32 判断前台窗口矩形是否覆盖整屏 + `WS_CAPTION` 缺失来识别全屏态，轮询 1~2s 足够。

**价值**：中高。收纳岛常驻置顶的天然代价是覆盖全屏内容（2026-11-18 实测冒烟时正好撞上全屏视频）——灵动岛在 iOS 之所以不烦人，是因为它内建于硬件；Windows 上的岛必须自己学会"让位"。这是岛能否长期常驻的体验分水岭。

**可行性**：中。winutil 已有窗口枚举/置底等 Win32 积累，新增 `is_foreground_fullscreen()` 即可；岛窗口配合 set_position 滑出/滑回（或 hide/show）。注意任务栏全屏（自动隐藏任务栏的误判）白名单处理。

**优先级**：⭐⭐ 中

## 2026-11-19

### 8. 下载目录智能整理（桌面之外的收纳延伸）

**创意描述**：把自动整理的监听范围从桌面扩展到「下载」文件夹（可开关、可自定义目录）：下载完成的文件（排除 *.crdownload/*.part 等半成品）按后缀规则自动/提示式归位，如安装包 → `收纳区\下载\安装包`、压缩包 → `收纳区\下载\压缩包`，或直接并入现有分类。

**价值**：高。下载目录是比桌面更失控的重灾区（测试环境事实：用户桌面 35 项待整理，下载目录通常数倍于此），元气/DeskGo 均把"下载整理"作为标配功能验证过刚需；PureDesk 的 watcher+move 管线天然可复用，等于零架构成本多吃一个高频场景。

**可行性**：高。`notify` watcher 已跑通桌面监听（watcher.rs），加一个目录实例即可；`move_path`/scan 排除规则现成；注意与浏览器"下载中"半成品扩展名的竞态（沿用现有 DEFAULT_EXCLUDES 的思路，mtime 稳定 3 秒才搬）。

**优先级**：⭐⭐⭐ 高

---

### 9. 重复文件感知：桌面与收纳区去重提示

**创意描述**：扫描时对桌面文件与收纳区做轻量指纹比对（同名+同大小，可选快速 hash），发现"桌面上的文件收纳区已有"时在待整理列表标"疑似重复"，一键选择：跳过收纳 / 收纳并把桌面副本送回收站。不做自动删除，只做提示。

**价值**：中。桌面最常见的混乱来源之一是同一文件反复下载/复制（report(3).pdf）；DeskGo 的清理线证明去重是用户真实诉求。与"删除只走回收站"红线一致，纯提示不越权。

**可行性**：中。同名+同大小比对零成本（scan 已返回 size）；真 hash 仅在用户点击"确认重复"时对候选对计算（大文件分块读），避免扫描期 CPU 尖峰。注意误报保护：只提示、永不静默删。

**优先级**：⭐⭐ 中

---

### 10. 桌面图标位置快照与一键复原

**创意描述**：提供"桌面图标布局快照"：一键整理/批量还原前自动记录桌面上每个图标的位置（含用户手动摆放的），并支持随时"恢复到某个快照"——桌面图标被意外打乱（分辨率切换、还原操作、他人乱动）后一键回到原样。快照存本地 JSON，保留最近 N 份可回溯。

**价值**：高。这是 Fences 虚拟派的招牌安全感（图标位置永远是用户的），物理移动派（元气/DeskGo）全都没有；PureDesk 的"一切可还原"人设目前只覆盖文件位置，不覆盖"图标的摆法"。对整理软件用户而言"我的桌面长什么样"同样是资产，补上后还原故事完整闭环。

**可行性**：中。读取桌面图标坐标走 SysListView32/IFolderView COM 路线（项目已有 COM Shell.Application 实战经验，memory 有先例），写入位置用 `IFolderView::SelectItem+SetItemPosition`；**风险点：Win11 对老式桌面 ListView 的兼容性需要实测**（部分机器下钩子方式失效），建议先做"快照只读 + 恢复尽力而为 + 失败明示"的保守版。

**优先级**：⭐⭐⭐ 高

---

### 11. 配置与布局导出/导入（备份与换机迁移）

**创意描述**：设置页加"导出配置/导入配置"：把分类规则（含自定义盒）、排除规则、盒子与收纳岛几何、图标大小等打包成单个 JSON 文件导出；换机/重装/给朋友装时导入即可完整复原收纳体系（可选连带"是否同时导出收纳区内容清单"）。

**价值**：中高。用户打磨出的盒子体系（名字/颜色/规则/摆位）是隐性资产，重装系统后从零重建最劝退；竞品几乎都不做配置迁移。这也是 GitHub 发布（release-plan.md 已规划 winget/官网）之后拉新分享的顺滑度补件——"导入我分享的 PureDesk 配置，30 秒复刻我的桌面整理"。

**可行性**：高。`Config` 已是单一 JSON 结构（serde 序列化现成），导出=下载 config.json 的美化副本+版本号标记，导入=校验+merge 策略（按分类 id 合并、几何可选覆盖）+ `save_config` 落盘 + `boxwin::sync`/`islandwin::sync` 刷新窗口；无新依赖。

**优先级**：⭐⭐ 中

### 12. 首次运行引导（三步上手）

**创意描述**：首次启动（或检测到桌面待整理 > 30 且从未整理过）弹出轻量三步引导：① 展示"你的桌面现状"（扫描数）→ ② 一屏说明收纳盒与收纳岛是什么（配一张示意图）→ ③ 问"现在就一键整理吗？"（立即整理 / 先自己逛逛 / 自定义建盒）。全程可跳过，完成后不再出现。

**价值**：中高。PureDesk 现在功能面已宽（盒子/岛/规则/排除/还原），新用户第一眼的信息密度是流失点；元气的新手引导是激活率的关键武器。引导里"检测桌面现状"那一步能把抽象功能变成"你桌面有 58 个待整理文件"的切身事实，转化率差别巨大。

**可行性**：高。纯前端实现（main.ts 首启判断 + 全屏遮罩向导 + 现有 api.scan/organize 数据），配置里加 `onboarding_done: bool`；无后端改动。

**优先级**：⭐⭐ 中

## 2026-11-20

### 13. 智能分组建议（lnk 目标聚类 → 推荐建盒）

**创意描述**：扫描桌面快捷方式的目标路径（IShellLink 解析，icons 模块已有 COM 积累），把指向同一安装目录/同一厂商的快捷方式聚成簇（如 12 个 lnk 都指向 `Tencent\*` → 建议"建一个「腾讯」盒，收纳这 12 个"）；主面板与收纳岛展示建议卡片，一键采纳即建盒并归位。

**价值**：高。自定义盒是 PureDesk 的核心差异化，但"手动策展 30 个盒"对游戏/工具重度用户是苦工——元气靠"智能整理推荐"降低了同样的门槛。把建议做在岛/主面板上（而非弹窗打扰），采纳一个建议=一次点击完成建盒+归类，让差异化能力从"能用"变"想用"。

**可行性**：中。lnk 目标读取用 IShellLinkW（`Win32_UI_Shell` feature 已在依赖中，icons.rs 已有 COM 初始化先例）；聚类启发式按目标目录前缀+厂商名分簇；只建议不自动建盒（保守）。注意 UWP 应用 lnk 的目标解析边界。

**优先级**：⭐⭐⭐ 高

### 14. 全局快捷键直达盒子（Ctrl+Alt+1..9）

**创意描述**：为前 9 个启用的收纳盒绑定全局快捷键 Ctrl+Alt+1..9（托盘右键每个盒显示其热键；可在设置改绑定）：按下即把对应盒子窗口唤至可交互态并短暂浮起（复用现有 Focused 钉底回落的窗口期），再按同键隐藏。数字顺序 = 设置页盒子列表顺序。

**价值**：中。键盘党的"秒开第 N 个盒"——比拖拽/点岛更快；对把 PureDesk 当"快速启动器"用的用户（自定义盒装满 lnk），热键直达让收纳盒事实上变成 9 组启动面板。竞品均无全局热键直达分组的能力。

**可行性**：高。`tauri_plugin_global_shortcut` 已注册 Ctrl+Alt+G/D（lib.rs:44-78 模式现成），加循环注册 + handler 里 `set_box_visible`/浮起即可；热键占用冲突时降级跳过并在设置页标灰。无新依赖。

**优先级**：⭐⭐ 中

### 15. 界面英文化（i18n，配合国际发布）

**创意描述**：前端字符串（主面板/盒子/岛/设置/对话框约 300 条）抽到 `src/i18n/{zh-CN,en}.ts`，语言跟随系统（可手动切换）；README 增加英文版节。这是纯前端工程，不涉及任何整理逻辑。

**价值**：中高。release-plan.md 已规划官网 GitHub Pages、winget 上架与国际加速——开源桌面工具的自然流量大头在英文世界，而桌面整理这个赛道英文区只有收费的 Fences；免费开源 + 英文界面是明确空档。i18n 是国际发布的前置工程，宜早不宜迟（越晚抽字符串成本越高）。

**可行性**：高。纯前端字符串映射 + `navigator.language` 探测；Rust 侧仅托盘菜单约 6 条（tauri menu 支持 localized 文案，顺手做）；术语表先定（Box/Island/Storage 整理区的英文叫法）避免返工。

**优先级**：⭐⭐ 中

## 2026-11-22

### 16. Explorer 右键"送入收纳盒"（任意位置一键收纳）

**创意描述**：给 Explorer 右键菜单加"送入 PureDesk 收纳盒"入口（注册表 context menu → 调 `puredesk.exe --send <路径>`）：在任何文件夹里对任意文件/文件夹一键送入收纳区（弹出轻量目标选择，或直接进兜底收纳盒）。不限于桌面——下载目录、微信接收文件、临时工作目录里的东西都能一纳入库。

**价值**：高。桌面只是收纳需求的起点，"从任何地方一键入盒"把 PureDesk 从"桌面整理工具"升级成"文件暂存归位器"，使用频次天花板大幅抬高；DeskGo 的右键菜单集成验证过这是高频刚需入口。且应用常驻托盘，响应是秒级体验。

**可行性**：高。`tauri_plugin_single_instance` 已能接收二次启动的 args（lib.rs:34-36），加 `--send` 参数解析即可把路径交给已有 `organize_paths` 管线；context menu 注册 = HKCU 注册表项（便携无管理员权限）；目标选择复用托盘/岛的选择 UI 或直接弹主面板定位。注意右键菜单文案中文显示与卸载清理注册表项。

**优先级**：⭐⭐⭐ 高

### 17. 整理风格预设模板（一键套用盒子体系）

**创意描述**：设置页/首次引导提供 3-4 套预设模板：「极简三盒」（收纳盒/文档/其他）、「标准九盒」（现有默认分类全启用）、「开发者」（工具/项目/素材/安装包…）、「 Gamer」（游戏/启动器/存档…），一键套用后进入可微调的分类页。模板只改分类启用集合与规则，不动已收纳文件。

**价值**：中高。新用户面对 9 个预设+自定义盒的空表格最容易流失（元气的新手引导同样靠预设解决）；模板把"配置成本"从逐项填表降为一次选择，且传达"这套工具能长成你自己的样子"。与 #12 首次引导天然衔接（引导第②步就是选模板）。

**可行性**：高。模板=内置的 `Vec<Category>` 快照常量，套用=确认对话框+覆盖 `categories`+`boxwin::sync` 重建盒子窗口；已收纳文件不需迁移（folder 名对得上则原位生效，对不上提示"旧内容仍在原文件夹"）。

**优先级**：⭐⭐ 中

---

### 18. 收纳区文件夹自美化（desktop.ini 图标与提示）

**创意描述**：为收纳区各分类子文件夹写入 `desktop.ini`（自定义文件夹图标 = 对应分类色的图标、info tip = 「PureDesk · 文档盒 · 由 PureDesk 管理」），并给存储根目录配专属图标。Explorer 里打开收纳区不再是千篇一律的黄文件夹，而是一套带分类色的视觉体系。

**价值**：中。收纳区是用户每天在 Explorer/岛里看见的地方，精致度直接决定"这个软件靠不靠谱"的直觉；成本几乎为零却显著提升完成度观感（元气/DeskGo 的收纳目录都有专属视觉）。另外专属图标让用户在"打开文件夹"场景一眼认出 PureDesk 管理的目录，是轻量的品牌曝光。

**可行性**：高。`desktop.ini` 是标准格式（`[.ShellClassInfo] IconResource / InfoTip`，需写入 localized name 时注意 memory 里 PowerShell 5.1 的无 BOM UTF-8 教训——由 Rust 写入天然规避）；生成分类色图标可用现有 image crate 动态渲染或内置一套资源；hide_storage_folder 开启时更不受干扰。卸载时注意清理（或随文件夹保留，无副作用）。

**优先级**：⭐⭐ 中
